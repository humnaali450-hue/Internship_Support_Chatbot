# Internship Support Chatbot

An AI-powered chatbot designed to answer common internship-related
questions and provide real-time support to interns.

## Features

- FAQ-based question answering
- NLP preprocessing
- TF-IDF vectorization
- Cosine similarity
- Automatic response generation
- Professional web interface
- Unknown question handling
- Testing

## Technologies

- Python
- NLP
- Scikit-learn
- TF-IDF
- NLTK
- Gradio
- Pandas
- NumPy

## How to Run

Install dependencies:

pip install -r requirements.txt

Train the model:

python src/train_model.py

Run the chatbot:

python run.py
